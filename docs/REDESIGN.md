# 表现力边界与重构方向

本文合并三件事：**问题归因**（实测数据）、**已试方案与结论**、**重构方向**。
目标是回答一个问题：继续调参能走多远？如果换数据结构与训练模式，能解决什么？

## 一、问题归因

当前设计有三处结构性约定，它们共同决定了失效形态：

| 约定 | 直接后果 | 实测 |
|---|---|---|
| 一个有效 UV texel = 一个高斯，数量由 `tex_size` 固定，无增删 | 采样密度训练前定死 | 30.4% 的三角面没有 texel（面积占 3.6%） |
| 每个 texel 的位置偏移自由，只受光度约束 | 观测不到处偏移无依据 | 可见高斯偏移中位 **27 mm**（头高 200 mm）；相邻 texel 偏移差中位 16.7 mm |
| 只有逐帧光度 L1，无几何/一致性先验 | 未观测区域没有支撑 | 40.5% 表面积从未朝外；20% 面积的面全透明 |

另一个隐含结果：因为一个 texel 要覆盖一整片，不透明度被学成**近似二值**——30% 在
1.0、64% 在 0.0，没有中间态，所以空洞边缘很硬。

**归因结论**：大问题来自"采样点不可增"，其次是"位置无约束"；数据覆盖是前提，
不是模型侧的错。

## 二、已试方案与结论

| 方案 | 结果 | 结论 |
|---|---|---|
| 用精修图做缺陷加权微调（SyncFix 输出） | 留出真值 +0.90 dB（286 帧全升），但高频能量 −13%、缺口仅 −1.9% | 外观对齐，不是结构修复 |
| 只改颜色 / 颜色+不透明度 | 比全参数版低约 0.15 dB | 尺度是必要项，但尺度只能"糊住" |
| A3 孔洞正则（权重 0.1） | 缺口 −89%，锐度 −51%，个别高斯尺度涨到 318 mm | 代理指标被投机，判失败 |
| A4 UV 邻域平滑（已实现，默认关） | 基线相对拉普拉斯 0.845，目标压到 0.5 以下 | 待验证 |

**共同模式**：每种方法都在优化一个代理指标，代价转移到了另一个指标上。这本身是
"表示层缺能力"的证据，而不是调参不够。

## 三、格式不变时还能做什么

数据覆盖充分时，以下改动不动 PLY 格式：

| 优化 | 做法 | 预期 | 成本 |
|---|---|---|---|
| 提高 `tex_size` | 256 → 320（配置项） | 每面 texel 中位 1.41 → 2.21，零 texel 面 30% → 23% | 高斯 ×1.56，渲染 10.9 → 约 17 ms |
| 几何一致初始化 | 尺度按 texel 的世界尺寸（UV 雅可比）初始化 | 少一些"微小高斯叠层" | 建绑定时算一次 |
| 颜色初始化 | 用数据集平均色 | 前几千步少走弯路 | 很小 |
| A4 邻域平滑 | `--smooth-weight 0.003` | 偏移场不再是白噪声 | 已实现 |
| SSIM 项 | 打开 `fused_ssim` | 抑制 L1 的过度平滑 | 每步一次 |
| 姿态均衡采样 | 按 yaw 分桶重采样 | 覆盖更均匀 | 采样器改造 |

这些都是"提高质量"，不是"改变能力上限"。

## 四、重构原则

保留 FLAME + 三角面绑定 + 约简基（K=20）+ `sh_degree=0`，改三处：

### P1 采样点与 texel 解耦

```
每个高斯: (face_id, bary, offset_local)
```

`bary` 可以是面内任意子位置，一个面 0 到多个高斯，数量由面积/曲率/误差决定。
UV 仍是纹理坐标来源（`bary @ face_uv`），可编辑性不丢。

### P2 训练即生长

沿用 3DGS 的 split / clone / prune，但限制在网格上：

```python
error_i = 该高斯覆盖像素上的渲染误差
grow    = (error_i > τ_err) and (grad_i > τ_grad)
split   = scale_i 大于局部面片尺度
prune   = opacity_i < τ_opacity
```

新点继承父点的 `(face_id, bary)`，约简基随行复制，所以动画代价不变。

### P3 位置有约束

- 逐面软边界：`|offset| ≤ c · 局部面片尺度`；
- UV 邻域平滑（已实现 `laplacian_penalty`）；
- 新点偏移初值取父点或邻域均值。

### P4 表达式驱动的不透明度与尺度

现在 `opacity` / `scaling` 是逐 texel 常数，不随表情变化（张口时口腔内壁要么一直
可见、要么一直透明）。加一个 129→64→2 的共享小 MLP 输出全局增益即可，参数量不到
一万，不改数据结构。

## 五、数据结构（两档）

### 档 A：静态容量 + 激活掩码（先做这个）

```
N_max = Σ_f ceil(area_f / cell²)     # 按面积分配，一次算好
xyz/rot/scale/opacity/color/face_id/bary 各 N_max 行
bases[K, N_max, ...], active[N_max] (bool)
```

- 生长 = 置 `active=True` 并初始化；剪枝 = 置 `False`；
- 张量定长，现有训练循环与光栅化直接可用；
- 代价是容量冗余。

容量参考（按面积分配）：256² × 1 = 60k，×2 = 126k（每面中位 3），×3 = 186k。

### 档 B：动态增删

用索引张量维护有效集合，分裂时 append。更省内存，但要重写训练循环与存档。

## 六、训练循环

```python
for it in range(steps):
    batch = sample()                       # 覆盖感知
    gs = bind_and_blend(params, mesh)      # 现有绑定路径
    out = render(gs, cam)                  # alpha 已含 active 掩码
    loss = L1 + ssim + λ_smooth * laplacian(xyz)
    loss += λ_hole * relu(0.3 - alpha)     # 只在高缺陷面
    loss.backward(); opt.step()

    if it % grow_every == 0 and it > warmup:
        stats = per_gaussian_error_and_grad()
        activate_or_split(stats, quota)
        prune(low_opacity, low_usage)
```

## 七、老问题在新结构里的处置

| 老问题 | 现结构 | 新结构 |
|---|---|---|
| 30% 三角面无采样 | 无法解决 | 按面积分配 + 生长 |
| ±40° 空洞 | 只能放大 → 糊 | 在空洞面激活新点，尺度不变 |
| 补洞变糊 | 必然 | 新增采样代替放大 |
| 偏移场噪声 16.7 mm | 无约束 | 邻域平滑 + 逐面软边界 |
| 不透明度二值、边缘硬 | 逐 texel 常数 | 更多采样 + 表达式驱动增益 |

## 八、代价与风险

- 渲染：N 从 6 万到 12–15 万，单帧 10.9 → 20–27 ms，实时通话需限制在 128k 以内；
- 训练：生长时要复制基（`[K,N,·]`），内存峰值上升；
- 存档：`weight_module` 现在挤在高斯列的前 P 行，N 变化会冲突，需拆成独立 section，
  并加 `active` 列；
- 基的一致性：分裂出的两点共享父点基，需在生长后允许微调。

## 九、第一步（可判定实验）

不重写，先做档 A 的最小版本：

1. `N_max = 2 × 现有容量`，按面积分配到面；
2. 只实现 `active` 与"按误差激活"，不做 split；
3. 同一份数据、同一套 16 个缺陷视角评测。

判据：`hole` 明显下降（且不是靠放大）、`spike` 不涨、锐度不降 → 方向成立，再投入
完整重写；若仍只能靠放大补洞 → 瓶颈在偏移与表达力，及时止损。
