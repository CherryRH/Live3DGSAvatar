# 表现力边界与已试方案（结论记录）

本文记录：**问题归因**（实测数据）、**已试方案与结论**、以及据此对方向的判断。
对应代码中的尝试（孔洞正则、邻域平滑、尺度上限、v2 容量分配）**已回退**，
此处保留结论与数据，供后续（尤其是换数据之后）参考。

## 一、问题归因

当前设计有三处结构性约定，它们共同决定了失效形态：

| 约定 | 直接后果 | 实测 |
|---|---|---|
| 一个有效 UV texel = 一个高斯，数量由 `tex_size` 固定，无增删 | 采样密度训练前定死 | 30.4% 的三角面没有 texel（面积占 3.6%） |
| 每个 texel 的位置偏移自由，只受光度约束 | 观测不到处偏移无依据 | 可见高斯偏移中位 **27 mm**（头高 200 mm）；相邻 texel 偏移差中位 16.7 mm |
| 只有逐帧光度 L1，无几何/一致性先验 | 未观测区域没有支撑 | 40.5% 表面积从未朝外；20% 面积的面全透明 |

另一个隐含结果：因为一个 texel 要覆盖一整片，不透明度被学成**近似二值**——30% 在
1.0、64% 在 0.0，没有中间态，所以空洞边缘很硬。

**归因结论**：大问题来自"采样点不可增"，其次是"位置无约束"；数据覆盖是前提，
不是模型侧的错。

## 二、已试方案与结论

| 方案 | 结果 | 结论 |
|---|---|---|
| 用精修图做缺陷加权微调（SyncFix 输出） | 留出真值 +0.90 dB（286 帧全升），但高频能量 −13%、缺口仅 −1.9% | 外观对齐，不是结构修复 |
| 只改颜色 / 颜色+不透明度 | 比全参数版低约 0.15 dB | 尺度是必要项，但尺度只能"糊住" |
| A3 孔洞正则（权重 0.1） | 缺口 −89%，锐度 −51%，个别高斯尺度涨到 318 mm | 代理指标被投机，判失败 |
| A4 UV 邻域平滑（已实现，默认关） | 基线相对拉普拉斯 0.845，目标压到 0.5 以下 | 待验证 |

**共同模式**：每种方法都在优化一个代理指标，代价转移到了另一个指标上。这本身是
"表示层缺能力"的证据，而不是调参不够。

## 三、格式不变时还能做什么

数据覆盖充分时，以下改动不动 PLY 格式：

| 优化 | 做法 | 预期 | 成本 |
|---|---|---|---|
| 提高 `tex_size` | 256 → 320（配置项） | 每面 texel 中位 1.41 → 2.21，零 texel 面 30% → 23% | 高斯 ×1.56，渲染 10.9 → 约 17 ms |
| 几何一致初始化 | 尺度按 texel 的世界尺寸（UV 雅可比）初始化 | 少一些"微小高斯叠层" | 建绑定时算一次 |
| 颜色初始化 | 用数据集平均色 | 前几千步少走弯路 | 很小 |
| A4 邻域平滑 | `--smooth-weight 0.003` | 偏移场不再是白噪声 | 已实现 |
| SSIM 项 | 打开 `fused_ssim` | 抑制 L1 的过度平滑 | 每步一次 |
| 姿态均衡采样 | 按 yaw 分桶重采样 | 覆盖更均匀 | 采样器改造 |

这些都是"提高质量"，不是"改变能力上限"。

## 四、重构原则

保留 FLAME + 三角面绑定 + 约简基（K=20）+ `sh_degree=0`，改三处：

### P1 采样点与 texel 解耦

```
每个高斯: (face_id, bary, offset_local)
```

`bary` 可以是面内任意子位置，一个面 0 到多个高斯，数量由面积/曲率/误差决定。
UV 仍是纹理坐标来源（`bary @ face_uv`），可编辑性不丢。

### P2 训练即生长

沿用 3DGS 的 split / clone / prune，但限制在网格上：

```python
error_i = 该高斯覆盖像素上的渲染误差
grow    = (error_i > τ_err) and (grad_i > τ_grad)
split   = scale_i 大于局部面片尺度
prune   = opacity_i < τ_opacity
```

新点继承父点的 `(face_id, bary)`，约简基随行复制，所以动画代价不变。

### P3 位置有约束

- 逐面软边界：`|offset| ≤ c · 局部面片尺度`；
- UV 邻域平滑（已实现 `laplacian_penalty`）；
- 新点偏移初值取父点或邻域均值。

### P4 表达式驱动的不透明度与尺度

现在 `opacity` / `scaling` 是逐 texel 常数，不随表情变化（张口时口腔内壁要么一直
可见、要么一直透明）。加一个 129→64→2 的共享小 MLP 输出全局增益即可，参数量不到
一万，不改数据结构。

## 五、数据结构（两档）

### 档 A：静态容量 + 激活掩码（先做这个）

```
N_max = Σ_f ceil(area_f / cell²)     # 按面积分配，一次算好
xyz/rot/scale/opacity/color/face_id/bary 各 N_max 行
bases[K, N_max, ...], active[N_max] (bool)
```

- 生长 = 置 `active=True` 并初始化；剪枝 = 置 `False`；
- 张量定长，现有训练循环与光栅化直接可用；
- 代价是容量冗余。

容量参考（按面积分配）：256² × 1 = 60k，×2 = 126k（每面中位 3），×3 = 186k。

### 档 B：动态增删

用索引张量维护有效集合，分裂时 append。更省内存，但要重写训练循环与存档。

## 六、训练循环

```python
for it in range(steps):
    batch = sample()                       # 覆盖感知
    gs = bind_and_blend(params, mesh)      # 现有绑定路径
    out = render(gs, cam)                  # alpha 已含 active 掩码
    loss = L1 + ssim + λ_smooth * laplacian(xyz)
    loss += λ_hole * relu(0.3 - alpha)     # 只在高缺陷面
    loss.backward(); opt.step()

    if it % grow_every == 0 and it > warmup:
        stats = per_gaussian_error_and_grad()
        activate_or_split(stats, quota)
        prune(low_opacity, low_usage)
```

## 七、老问题在新结构里的处置

| 老问题 | 现结构 | 新结构 |
|---|---|---|
| 30% 三角面无采样 | 无法解决 | 按面积分配 + 生长 |
| ±40° 空洞 | 只能放大 → 糊 | 在空洞面激活新点，尺度不变 |
| 补洞变糊 | 必然 | 新增采样代替放大 |
| 偏移场噪声 16.7 mm | 无约束 | 邻域平滑 + 逐面软边界 |
| 不透明度二值、边缘硬 | 逐 texel 常数 | 更多采样 + 表达式驱动增益 |

## 八、代价与风险

- 渲染：N 从 6 万到 12–15 万，单帧 10.9 → 20–27 ms，实时通话需限制在 128k 以内；
- 训练：生长时要复制基（`[K,N,·]`），内存峰值上升；
- 存档：`weight_module` 现在挤在高斯列的前 P 行，N 变化会冲突，需拆成独立 section，
  并加 `active` 列；
- 基的一致性：分裂出的两点共享父点基，需在生长后允许微调。

## 九、格式版本与代码隔离

改格式不影响渲染：渲染层只吃 `GaussianSet`（xyz / rotation / scaling / opacity /
color）与 `Camera`；`deform` 只依赖 `Binding(face_id, bary)`。**新格式只要仍产出这两样，
渲染、GUI、在线驱动都不用改。**

需要隔离的只有三处：

| 位置 | 现状假设 | 隔离方式 |
|---|---|---|
| `core/io/ply.py` | 每高斯一行；`n ≤ tex_size²`；MLP 压在前 P 行 | 按 `format_version` 分派；v2 用 sidecar 存 MLP |
| `core/deform/binding.py` | UV 光栅化 → texel 中心 | 增加 `capacity_binding`（方案；代码已回退） |
| `evaluation/defects.py` | `per_texel` / `build_defect_map` 需要 texel 索引 | v2 跳过"回填 UV 图"，只用逐高斯质量 |

### 版本标记

PLY 头 `comment gaussian_config` 里的 JSON 增加 `format_version`（当前 `1`）；
缺失视为 v1（兼容参照实现与旧文件），**未知版本直接报错**而不是猜。
（方案；对应实现已回退到 v1，见 git 历史 `fa24fae` / `3f95836`。）

v2 的元数据形如：

```json
{"format_version": 2, "tex_size": 256, "num_basis_in": 129,
 "num_basis_blend": 20, "mlp_hidden": [128, 128], "use_weight_proj": true,
 "capacity": {"density": 2.0, "n_max": 125719, "n_active": 125719},
 "has_active": true, "has_texels": false}
```

- 每高斯列不变，**多一列 `active`**；
- MLP 参数移到 sidecar `model.extra.npz`（N 与 MLP 参数量解耦，生长时不再冲突）；
- `load_ply` 内部按版本分派，**返回同一个 `GaussianAvatar`**，所以下游全部复用。

### 新旧模型对比

两者都 load 成 `GaussianAvatar`，属性名一致，所以：

| 工具 | 是否直接可用 |
|---|---|
| `render_test.py`（留出集质量） | ✅ |
| `compare_defects.py`（缺口/尖刺/云外溢） | ✅ 只用 `binding_face_id` 与 alpha |
| `compare_model_stats.py`（参数分布） | ✅ 只读属性 |
| `analyze_failure_modes.py`（姿态暴露） | ✅ 偏移语义不变 |
| `find_defects.py` 的 `mass.npz` | ⚠️ v2 的逐高斯顺序不同，需各自生成；逐 texel 图仅 v1 |

## 十、第一步（可判定实验）

不重写，先做档 A 的最小版本：

1. `N_max = 2 × 现有容量`，按面积分配到面；
2. 只实现 `active` 与"按误差激活"，不做 split；
3. 同一份数据、同一套 16 个缺陷视角评测。

判据（**必须一起看**）：

| 指标 | 通过条件 | 为什么 |
|---|---|---|
| `hole` | 明显下降 | 结构缺口 |
| `云外溢` | 不上升 | 否则"缺口消失"只是点云盖到了网格外面 |
| `spike` | 不涨 | 表面没有碎裂 |
| 锐度比 | ≥ 0.85 | 没有用模糊换填满 |
| 留出 PSNR | ≥ 基线 −0.2 dB | 没有牺牲重建质量 |
| `scale_mm_max` | 与基线同量级 | 没有靠个别巨型高斯 |

若 `hole` 下降但 `云外溢` 上升，说明模型是"把点云铺得比网格更大"，属假通过——
2026-11-09 的 `cap2` 就是这种情况（`hole` 0.170→0.004，但 `云外溢` 0.28→0.65）。

**首次对照的结果（负）**：把容量翻倍（60k → 126k）且关掉孔洞正则后，缺陷视角的指标
几乎不动：

| 指标 | `run` | `cap2_clean` |
|---|---|---|
| 结构缺口 | 0.1702 | 0.1728（+1.6%） |
| 云外溢 | 0.28 | 0.28（持平） |
| 尖刺 | — | 持平 |
| 锐度 | 4.27 | 4.21（−1.4%） |
| 不透明度 >0.5 | 23.4% | 15.2%（点更小更透） |
| 尺度中位 | 0.550 mm | 0.490 mm |

也就是说：**缺的不是采样点**。多出来的点被模型分成了更小、更透明的点，表面的实际
覆盖没有变化。按这个结果，第二步"按误差激活新点"也不会改变缺口——它与这次实验同属
"增加点"这一族。

剩下的嫌疑是**位置**：偏移中位 27 mm、且只在被观测视角下受约束。当时用一次性
消融脚本（把偏移直接置零/截断，不训练）检验，结论是偏移**承载细节**、不能去掉：

```text
run_zero：缺口 0.170 → 0.186，锐度 −16.8%
```

脚本已随回退一起删除；结论保留在本文与 ENHANCE 的边界说明里。

**结果（也是负）**：把偏移归零后，缺口反而略升，外观大幅变差：

| 指标 | `run` | `run_zero` |
|---|---|---|
| 结构缺口 | 0.1702 | 0.1858（+9.2%） |
| 云外溢 | 0.28 | 0.29（持平） |
| 锐度 | 4.27 | 3.56（−16.8%） |
| 与精修图 PSNR | — | **−9.44 dB** |

说明偏移是**有用的**：它承载了光度拟合所需的位置细节；把它按回网格会让表面更糟。
"偏移漂移导致空洞"这个假设不成立。

## 三组对照的合并结论

| 实验 | 变量 | 缺口变化 | 结论 |
|---|---|---|---|
| `cap2`（含孔洞正则） | 采样 ×2 + 正则 | 0.170 → 0.004 | 假通过（云外溢 0.28→0.65） |
| `cap2_clean` | 仅采样 ×2 | 0.170 → 0.173 | 采样密度不是瓶颈 |
| `run_zero` | 偏移归零 | 0.170 → 0.186 | 位置不是"错误"，是有用的自由度 |

三条路都排除了模型侧"调参/加密/归零"能解决 ±40° 空洞的可能。剩下的是**数据覆盖**：
40.5% 的表面积在训练数据里从未朝外，模型没有可用于约束的信息。

还有一个测量上的前提要说明：`hole` 用 **FLAME 网格投影**作为"这里应该有表面"的
参照，而网格本身在这些角度也没有被跟踪验证过。因此更靠得住的验证方式是：**用覆盖
更广的数据重训后，直接用 `render_test` 在留出的宽角度真实帧上测 PSNR**——那时
参照是真图，而不是未经验证的网格。
